# Биллинг и Экономика сервиса

## Концепция Токенизации

В NeuroFox реализована гибкая экономическая модель, основанная на **Токенах**. Это позволяет абстрагировать стоимость различных AI-операций (от простых текстовых запросов до тяжелой генерации видео) и предоставлять пользователям прозрачную систему оплаты.

### Почему это эффективно:
- **Универсальность:** Один баланс для всех типов контента.
- **Микротранзакции:** Возможность покупки небольших пакетов для разового использования.
- **Лояльность:** Легкое начисление бонусов и кэшбэка в рамках маркетинговых акций.

## Гибридная система балансов

Ключевой особенностью биллинга является разделение токенов по их происхождению и жизненному циклу:

1.  **Подписочный баланс (Subscription Tokens):**
    - Входит в состав ежемесячных тарифов.
    - Имеет ограниченный срок действия (30 дней).
    - **Приоритет:** Списывается в первую очередь, защищая вложения пользователя.
2.  **Пакетный баланс (Package Tokens):**
    - Приобретается разово.
    - Не имеет срока годности ("вечные" токены).
    - Используется только после исчерпания подписочного лимита.

## Платежные решения

Бот интегрирован с ведущими платежными шлюзами для обеспечения высокой конверсии:

- **YooKassa / Prodamus:** Прием карт РФ и СНГ, СБП.
- **Telegram Stars (XTR):** Официальная внутренняя валюта Telegram для соблюдения политик App Store и Google Play.

### Автоматизация оплат:
1.  **Генерация счета:** Автоматическое создание ссылки на оплату через API шлюза.
2.  **Обработка вебхуков:** Асинхронное зачисление средств. Пользователь получает уведомление о пополнении в течение нескольких секунд после оплаты.
3.  **Безопасность:** Система проверяет уникальность ID транзакции, исключая повторные зачисления.

## Реферальная программа и Партнерство

Для органического привлечения трафика внедрена многоуровневая партнерская система:

- **Виральность:** Уникальные реферальные ссылки для каждого пользователя.
- **Бонусы за регистрацию:** Автоматическое начисление токенов приглашенному и пригласившему.
- **Revenue Share:** Процент с каждой покупки реферала зачисляется на отдельный "Партнерский баланс".
- **Личный кабинет:** Просмотр статистики приглашений и управление накопленным кэшбэком прямо в боте.
