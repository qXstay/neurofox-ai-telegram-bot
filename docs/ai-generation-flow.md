# Жизненный цикл AI-генерации

## Управление сложными задачами

Генерация высококачественного контента (особенно видео) — это длительный процесс, требующий надежной системы обработки и уведомлений. В NeuroFox реализован промышленный подход к управлению AI-задачами.

### 1. Валидация и Резервирование (Hold)
Прежде чем отправить запрос к AI-провайдеру, система выполняет:
- **Проверку лимитов:** Хватает ли у пользователя токенов на выбранную модель.
- **Мягкое списание:** Токены "замораживаются". Если генерация прервется ошибкой на стороне API, система автоматически вернет их на баланс.

### 2. Асинхронное исполнение
Поскольку генерация может занимать от 30 секунд до нескольких минут, бот не "блокирует" пользователя:
- **Task ID:** Получение уникального идентификатора задачи от провайдера.
- **Background Polling:** Фоновые воркеры опрашивают статус задачи с экспоненциальной задержкой (Backoff), чтобы не перегружать API.

### 3. Обработка результатов и Доставка
- **Оптимизация медиа:** Полученный контент (фото/видео) может быть пережат или сконвертирован для оптимального отображения в Telegram.
- **S3 Storage:** Ссылка на файл сохраняется в базе данных, а сам файл загружается в облачное хранилище. Это позволяет пользователю скачивать свои работы из истории в любое время.
- **Уведомление:** Как только статус меняется на `success`, бот отправляет результат пользователю, используя сохраненный `message_id` панели управления.

## Интеллектуальная обработка ошибок

Коммерческий сервис должен быть устойчив к сбоям внешних API. В проекте реализованы:
- **Авто-ретраи:** При временных сетевых ошибках или перегрузке API (Rate Limit).
- **Информативные статусы:** Вместо молчания или технических логов пользователь видит понятные статусы: "В очереди", "Генерация...", "Загрузка видео...".
- **Refund Policy:** Если задача завершилась со статусом `failed` (например, из-за модерации контента или технического сбоя провайдера), токены автоматически возвращаются пользователю.

## Предобработка контента

Для обеспечения высокого качества результата бот выполняет автоматическую подготовку данных:
- Проверка форматов входных изображений.
- Адаптация текстовых промптов (добавление необходимых ключевых слов для улучшения качества).
- Ограничение нагрузки на API через систему семафоров.
