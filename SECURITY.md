# Безопасность публичного кейса

Этот репозиторий — безопасная публичная версия коммерческого проекта.

В нём нет:
- токенов Telegram-бота;
- ключей AI API;
- платёжных ключей;
- базы данных;
- логов;
- данных пользователей;
- реальных транзакций;
- приватной бизнес-логики заказчика;
- полного боевого кода проекта.

## Что заменено

Все чувствительные значения заменены на демонстрационные шаблоны в `.env.example`.

Примеры:
- `__PUT_API_KEY_HERE__`
- `__PUT_SECRET_HERE__`
- `__PUT_DATABASE_URL_HERE__`

## Что показано

В репозитории оставлены только безопасные материалы:
- описание продукта;
- скриншоты интерфейса;
- документация по архитектуре;
- демонстрационные примеры кода;
- упрощённый архитектурный срез с тестами.

## Перед публикацией

Перед загрузкой на GitHub дополнительно проверено, что в репозитории нет `.env`, баз данных, логов, дампов и приватных файлов.
