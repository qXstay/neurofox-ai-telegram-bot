# Architecture Shell: NeuroFox AI Bot

Этот раздел представляет собой «архитектурный срез» проекта, демонстрирующий применение принципов **Clean Architecture** и **Ports & Adapters**.

## 🎯 Цель модуля

Данный код не является копией продакшн-системы. Его задача — показать:
1.  **Разделение ответственности:** Бизнес-логика (Domain/Services) полностью независима от внешних API и баз данных.
2.  **Тестируемость:** Использование инверсии зависимостей позволяет легко тестировать сложные сценарии (биллинг, реконсиляция) через Fake-адаптеры.
3.  **Агностичность к инфраструктуре:** Легкая замена InMemory-репозиториев на PostgreSQL или Redis без изменения логики сервисов.

## 🏗 Архитектурные слои

- **Domain Models:** Чистые сущности проекта (User, Payment, Task).
- **Ports (Interfaces):** Определение контрактов для взаимодействия с внешним миром (AI Providers, Repositories).
- **Services:** Реализация сложной бизнес-логики (правила списания токенов, управление жизненным циклом генерации).
- **Adapters (Fakes):** Демонстрационные реализации портов для запуска тестов без внешних зависимостей.

## 🧪 Реализованные тестовые сценарии

Модуль включает `pytest` тесты, покрывающие критические бизнес-процессы:

1.  **Billing Priority:** Проверка приоритетного списания подписочных токенов перед покупными.
2.  **Insufficient Funds:** Гарантия отказа в обслуживании при нехватке средств на балансе.
3.  **Generation Flow:** Постановка задачи, резервирование токенов и обработка результатов.
4.  **Payment Idempotency:** Защита от двойного начисления токенов при повторных вебхуках.
5.  **Payment Reconciliation:** Автоматическое восстановление «зависших» платежей через опрос провайдера.

## 🚀 Запуск тестов

Для запуска демонстрационных тестов выполните:

```bash
# Переход в папку (из корня репозитория)
cd _public_showcase/architecture-shell

# Установка зависимостей (нужен Python 3.11+)
pip install -e ".[test]"

# Запуск тестов
pytest
```
