# Скриншоты проекта

В этой папке находятся изображения, демонстрирующие интерфейс бота NeuroFox AI. 

## Актуальный список файлов:

1. `cover.png` — Обложка проекта.
2. `01-main-navigation.png` — Главное меню (навигация по основным разделам).
3. `02-image-generation.png` — Интерфейс генерации изображений.
4. `03-special-modes.png` — Специальные режимы (ретушь, изменение фона и др.).
5. `04-video-generation.png` — Генерация видео по промптам.
6. `05-ai-chat-settings.png` — Настройки AI-чата (выбор моделей, параметры).
7. `06-tariffs-payments.png` — Система тарифов и платежный интерфейс.
8. `07-music-scenarios.png` — Сценарии генерации аудио и музыки.

---

## 🛡 Sanitization & Privacy

Все скриншоты в данной папке прошли предварительную обработку:
- **Удалены персональные данные:** замазаны User IDs, Usernames и личные сообщения.
- **Очищены ссылки:** удалены прямые платежные ссылки и специфические домены.
- **Безопасность:** интерфейс демонстрирует только функциональные возможности без раскрытия конфиденциальной информации клиентов.

*Данные скриншоты подготовлены специально для публичной демонстрации Case Study.*
